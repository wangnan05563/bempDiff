## 根因
本单不是缺陷，而是 MTask 台账卫生职责：派生单按「四步闭环」应为
**回传 result → 归并回原单 → 标注 done → 归档**，但历史上有两单只走完前三步——
回传时服务端已把内容自动整合回原单（`已同步处理结果…并已整合回原任务`），
`done` 也标了，**唯独漏了归档**，于是它们在「已完成」列表里长期挂账，
看起来像还有待办动作，掩盖了真实的剩余工作集合。
