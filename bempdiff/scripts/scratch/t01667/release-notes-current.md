## 本版唯一差异（相对 0.1.2026100801）

- **修复：API Key 误删防护在「本会话保存过一次配置」后失效**（T01615 / T01622 真实安装版复验发现）。
  前端保存配置时把 **PUT 请求体** 当成新的配置态写回内存，而请求体不含 `hasApiKey` 字段，于是「密钥已落盘」这一事实在页面上永久失明：
  随后取消勾选「记住 API Key」并保存时，**不再弹二次确认，直接把 properties 里的密钥行删掉**（默认安全模式不回显明文，删后只能凭记忆重填）。
  现改为采用 **服务端回读**（PUT 返回的就是含 `hasApiKey` 与按持久化语义的明文回显的配置快照）。

## 请使用本版替代 0.1.2026100801

0.1.2026100801 含上述回归，已在该 Release 说明中标注不推荐安装。

## 沿袭 0.1.2026100801 的全部改动

- **配置中心 API Key 可见性**（T01567）：输入框不再被空的本地草稿遮蔽，已持久化的密钥直接返显；框内为空时按状态给出可读提示。
- **误删密钥防护**（T01615）：取消勾选「记住 API Key」后保存先弹二次确认；新增「清除已保存密钥」显式入口；取消确认不产生任何写请求。
- **性能：二次比对极慢根因修复**（T01546）：嵌套解包 memo 改为 CAS 预留 + 作业级/全局双层级联回收。
- **更新通道对齐**（T01546）：桌面壳向渲染层暴露安装包版本；仅当 Release 标签本身是版本号时才比较，消除恒报「发现新版本 vbempDiff」的误报。
- **一键更新修复**：「立即更新」下载不再因 HTTP 302 重定向失败。
- **中英双语收口**（T01508）与 **质量**（T01550/T01549）：同上一版。
