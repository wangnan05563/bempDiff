## 差异文件树缩进失效修复（09:13，用户反馈"看不出层次感"）
- **现象**：树视图下 bemp-served/WEB-INF/classes/properties/lib 缩进几乎为 0，所有节点左对齐挤在一起。
- **根因**：DiffTree.vue 模板上 dir/file 节点带 Bootstrap `px-2` utility（`padding-left: 0.5rem !important`），其 `!important` 优先级高于 `:style="rowStyleFor(row)"` 的内联 paddingLeft（无 !important）→ 全部节点左内边距被锁 8px，缩进无效。
- **修复**（DiffTree.vue `rowStyleFor`）：
