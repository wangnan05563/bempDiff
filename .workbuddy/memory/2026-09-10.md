### 实测技术要点（可复用）
1. **AV 节流下全量哈希代价极高**：`src-tauri/target` 1,622 MB 全量 SHA-256 跑 **7 分 45 秒**仍未完（后台更慢）；改「隔离桶全量 + 删除桶 ≤1MB 全量 / >1MB 首 64KiB 采样指纹」+ 8 线程 → **7.6 秒**。可再生构建缓存无需全量哈希。
2. **`build_targets` 混用 `os.walk` 绝对路径与 `os.path.relpath` + `os.path.join(ROOT, rel)` 会产生同名不同串的绝对路径**（`D:\...\dir/file` vs `D:\...\dir\file`），按 `abs` 字符串去重失效 → 计划数虚高 163（5,094 vs 实际 4,927），且 .class 会被「删除桶」先命中而非按预期走隔离。修法：`os.path.normcase(os.path.normpath(abs))` 作去重键。
3. **`kind` 应按条目本体而非命中规则归类**：同一 `.class` 既被 `compiled_dirs` 目录规则命中（kind=build-output/cache）又被 `compiled_class_patterns` 命中（kind=compiled-class），按规则归类会导致报表口径分裂（198 → 31）。改为按后缀归一化。
4. **文件占用探测**：`CreateFileW(path, GENERIC_READ, dwShareMode=0, ..., FILE_FLAG_BACKUP_SEMANTICS)` 返回 `INVALID_HANDLE_VALUE` 且 `GetLastError()==32 (SHARING_VIOLATION)` 即锁定；对目录也需 `FILE_FLAG_BACKUP_SEMANTICS`。447 处探测 0 锁定。
5. **区分「本项目服务」与「外来 java 进程」**：`tasklist` 只能看到通用 `java.exe`，必须 `wmic process get ProcessId,Name,ExecutablePath,CommandLine` 看命令行——本次 6 个 java.exe 全是 Trae 语言服务器/Jenkins/spring-boot LS，**没有一个是 BempDiff 后端**，因此端口无监听时可直接放行。
6. **tracked-but-ignored 检测**：`git ls-files | git check-ignore --stdin --no-index` 一步列出「已入库但被忽略规则命中」的历史垃圾（本次 26 个），是 `.gitattributes export-ignore` 的精确输入。
7. **隔离区放工作空间外**（`<父目录>/.cleanup-quarantine/<项目>-<ts>/`）同盘移动秒级完成，且工作空间体积真实下降；放工作空间内则「释放空间」报表失真。
8. 沙箱删除仍只认 ctypes：`DeleteFileW` / `RemoveDirectoryW` 逐文件 + 自底向上删空目录；`shutil.rmtree`/`os.remove` 会触发 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`。归档临时工作目录时 `shutil.copy2` 可用（复制非删除）。
9. `git commit -- <pathspec>` 可在 index 已有他人暂存改动时**只提交指定文件**，避免夹带（本次 index 预存 4 个 package*.json 改动）。

### 由此推翻我第一版重建的三处遗漏
| # | 原版实际内容 | 我的第一版 |
|---|---|---|
| 1 | `customInit` / `customUnInstall` 宏内 `nsExec::ExecToLog 'taskkill /f /t /im BempDiff.exe'`（安装/卸载前关闭运行实例） | ❌ 完全没有 |
| 2 | `preInit` 宏与 `ensureDiskSpace` 包在 `!ifndef BUILD_UNINSTALLER` 内 | ❌ 没有（会触发 warning 6010） |
| 3 | 编码 **UTF-8 带 BOM** + CRLF（项目约定：含中文脚本须带 BOM） | ❌ UTF-8 无 BOM + LF |

**为什么 1 必需**：electron-builder 24.13.3 **无 `nsis.killRunningApp`**；若 BempDiff.exe / javaw sidecar 在运行，安装器覆盖 exe/jar/JRE DLL 会报 `Access is denied`，并可能把**旧 jar 打进包**造成 STALE。
**为什么 2 必需**：electron-builder 会编译 `BUILD_UNINSTALLER` 过渡卸载器且以 **`-WX`（警告即错误）** 编译；未被引用的 `ensureDiskSpace` 触发 **warning 6010** → 构建失败。
**演变史**（topics.md 2026-08-30）：初版 `preInit` 会检查 `$INSTDIR` 所在盘与系统盘剩余空间、<512MB 则中止并给准确提示、查询失败则跳过 → 后确认该预检本身就是误报源 → 改为 `ensureDiskSpace` **立即 Return** 彻底绕开（另一半是 `nsis-tpl/common.nsh` 的 `SectionSetSize 1`）。

### 最终重建件（4,298 B，UTF-8 BOM + CRLF）
结构 = `customInit`(taskkill) + `customUnInstall`(taskkill) + `!ifndef BUILD_UNINSTALLER { preInit → Call ensureDiskSpace; Function ensureDiskSpace → Return }`。文件头完整标注为「重建件非原版」+ 事实来源 + 演变史。
