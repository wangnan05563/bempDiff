## 19:5y DiffView 超大 diff 虚拟滚动
- **背景**：后端 `MAX_LCS_CELLS=16_000_000` 守卫已让超大 diff 以「整体替换」("- "/" + ") 形式返回（不再 OOM），但前端 `DiffView.vue` 原用 `v-for` **全量渲染每一行 DOM**——万行级 diffText 直接冻结浏览器/Electron（CPU 100% + 卡死）。这是 P1「大文件无虚拟滚动」项的落地。
- **实现（`webui/src/components/DiffView.vue`）**：
  - 窗口化渲染：`scrollTop`/`viewportH` 由 `onDiffScroll`/`ResizeObserver` 维护；`offsets` 前缀和（prefix-sum）给每行绝对 `top`；`findStart/findEnd` 二分定位可见区间；`visibleRows` 仅切片可见行 + `OVERSCAN=12` 缓冲；`diff-grid` 高度 = `totalHeight`（真实行高之和），行 `position:absolute` 绝对定位。
  - 动态行高：因 `wrap` 模式行会换行 → 行高不定。`setRowRef` 收集 DOM、`onUpdated`→`measureVisible()` 读 `el.offsetHeight` 回写 `heights[abs]`（>0.5px 差才更新，避免抖动）；`offsets`/`totalHeight` 随 `heights` 重算。
  - `ResizeObserver` 监听 `diffAreaRef` 尺寸变化（wrap 重排/容器缩放）→ 重置 `heights` 全量重测，防错位。
  - `locate(idx)`（上一处/下一处差异定位）改写：目标行可能不在 DOM，改按 `displayRows` 找到对应 `di`，用 `offsets[di]` 直接 `scrollTo`（不再依赖元素在 DOM 内）。
  - `EST_ROW_H=20` 兜底：内容未就绪时用估算行高（`heights[len-1]` 默认 20），首屏不塌成 0。
  - `watch(displayRows)`：内容切换时重置 `heights` + 滚动到顶；`watch(node&&dec&&dec.ok)`：文件就绪时初始化 viewport + 重置 heights。
  - 模板：`diff-area`(@scroll) → `diff-grid(:style height)` → `v-for visibleRows`（`:key` 用 `r.ri>=0?'r'+ri:'f'+abs`，`:ref` 收集，`:style` 绝对 top）；内联 diff/折叠/fold/goto-prev-next/flash 高亮全部保留（仅渲染层从全量改为窗口）。
