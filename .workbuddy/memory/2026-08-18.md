## 15:1x 修复「记住 API Key」开关重启后丢失（ServerConfig 持久化漏字段）

## 19:5y DiffView 超大 diff 虚拟滚动 + 异步渲染优化（大文件切换卡顿根治）
- **背景**：用户反馈「切换差异标签页时，文件体积过大 → 长时间卡顿」。探查磁盘版 `DiffView.vue` 发现**前序会话写的虚拟滚动实现已被 `git restore` 回退**，退化为「全量 `v-for displayRows` + 全量 `inlineMap` 行内 LCS」——大文件（数万行）切换即全量构造 + 全量 DOM + 全量 LCS，主线程长阻塞，即卡顿根因。
- **核心常量**：`EST_ROW_H=21`（行高估算，measureVisible 回填）/`OVERSCAN=12`（视口缓冲）/`CHUNK=5000`（解析分块）/`PARSE_SYNC_LIMIT=20000`（阈值内同步免闪）/`OVERSIZED_LINES=60000`（超阈值降级简洁视图）。

  4. **超大降级**：`oversized=rows.length>OVERSIZED_LINES` → 关行内高亮（`inlineOn`）+ 默认 `collapse=true`（折叠未变）；`oversized-banner` 显示增/删/未变统计，用户可「展开完整差异」(`forceFull` 重开高亮+展开)。
