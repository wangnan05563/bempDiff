## 修复详情

### 1. S1068 - 移除未使用字段 (App.java)

**问题**: 4 个 `Tab` 类型字段 (`summaryTab`, `fileTab`, `destructiveTab`, `auditTab`) 声明为私有字段但从未被类方法直接引用（仅作为局部变量在 `buildCenter()` 中使用）。

**修复**: 删除这 4 个字段声明，因为它们只在 `buildCenter()` 方法中作为局部变量使用。

### 2. S1117 - 变量遮蔽 (App.java)

**问题**: `buildCenter()` 方法中的局部变量 `summaryTab`, `fileTab`, `destructiveTab`, `auditTab` 遮蔽了同名的字段。

**修复**: 由于字段已被删除，遮蔽问题自然消除。

### 3. S2864 - 迭代 entrySet 而非 keySet (App.java)

**问题**: `onAnalyze()` 方法中迭代 `decompiled.keySet()` 然后对每个 key 调用 `decompiled.get(k)`，效率低于直接迭代 entrySet。

**修复**: 改用 `for (Map.Entry<String, DecompiledUnit> e : decompiled.entrySet())` 迭代。

### 4. S2259 - 可能的 NPE (DiffEngine.java)

**问题**: 在 `compute()` 方法的 `else if` 分支中，`o` 已经被前面的条件 (`o != null && n == null` 和 `o == null && n != null`) 排除为空的可能性，但 SonarQube 静态分析仍然认为 `o` 可能为 null。

**修复**: 添加显式的 `o != null` 检查以消除 NPE 警告。
