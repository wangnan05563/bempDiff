### 1.1 【修改】多 hunk 行号重置（评审 #2 / B1） — 新文件 L38–52

```js
let inHunk = false
for (const raw of d.diffText.split('\n')) {
  const hunk = /^@@ -(\d+)(?:,\d+)? \+(\d+)(?:,\d+)? @@/.exec(raw)
  if (hunk) {
    inHunk = true
    leftNo = parseInt(hunk[1], 10) - 1
    rightNo = parseInt(hunk[2], 10) - 1
    continue
  }
  if (raw.startsWith('\\')) { inHunk = true; continue }
  if (!inHunk && (raw.startsWith('--- ') || raw.startsWith('+++ '))) continue
```

四态语义：① 缺省该字段 → 保持不变（前端未改即 omit，保留服务端已存密钥）；② 显式空串 `""` → 清除密钥；③ 含 `****` 掩码串 → 防御性忽略，保持原值；④ 其它非空串 → 设为新值。配套单测 `ServerConfigTest.java`（新增，6 断言）覆盖上述四态 + 掩码格式。
> 后端 `handleAiTest` 的掩码防御（`!k.contains("****")` 才覆盖）见 §6.8，与此处协议呼应，杜绝「掩码串覆盖真实密钥」。
