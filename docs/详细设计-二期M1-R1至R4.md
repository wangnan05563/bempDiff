## 2. 技术方案

### 2.1 R1 过滤缺口补齐（改 `webui/src/components/DiffTree.vue`）

1. **命中计数**：新增 `hitCount = computed(() => filtered.value.length)`；在 pane-head 的「{{ tree.length }} 项」旁，当任一过滤生效时显示 `{{ hitCount }} / {{ tree.length }}`（样式：次要色小字；无过滤时维持原样不增噪）。过滤生效判定：`filterSearch` 非空 || 任一 filterShow* 为 false || filterRisk 非空 || excluded/ignore 命中。
2. **过滤栏收起**：`state.config` 新增 `treeFilterBarVisible`（默认 true，持久化随 config 走，天然满足「重启记忆」）；「...」视图菜单新增「显示过滤栏」勾选项（对齐既有 dropdown-item 模式）；收起时隐藏 `.dt-toolbar` + `.dt-filters` 两个区块，保留 pane-head 一行 + 命中计数徽标（保证收起后仍能看到命中/总数）。
3. **验收对齐 PRD**：清空还原（clearAllFilters 已有）；过滤状态切换文件/展开折叠后保持（过滤谓词在 computed 链上，天然保持）；命中数实时显示。

### 2.2 R2 Diff 视图增强（改 `webui/src/components/DiffView.vue` + `store.js`）

1. **行级选中与复制**：
   - 状态：`selRows = ref(new Set())`（以行号 `_i` 为键，split/unified 两侧行同源共享行号）；`selectionAnchor` 支持 Shift 范围选择。
   - 交互：行首 gutter 列增加复选热区（hover 显现，避免视觉噪声）；Ctrl/Cmd+A 在 diff 面板聚焦时全选可见行（规避 GitHub Desktop #20049 同类语义错乱——焦点在 Find 输入框时不劫持）。
   - 复制：复用既有 copyText helper；复制格式「可选行号前缀 + 行内容」，行号前缀开关挂到 View 菜单（`diffCopyWithLineNo`，默认关）。
2. **diff 内查找（Find）**：新增 `lib/diff_search.js`（纯函数：输入折叠后行数组 + 关键字 → 命中行号列表 + 行内偏移），DiffView 增加顶部浮动 Find 条（`Ctrl+F` 唤起 / `Esc` 关闭）：上一个/下一个/全部高亮、命中计数「3 / 17」；高亮渲染走现有 segs 渲染链路的 mark span。万行文件性能要求 ≤300ms（纯线性扫描，单 pass 实现）。
3. **二进制占位摘要卡**：后端 tree node 已有 `size`；包模式 SHA 需后端在 node 上补 `sha256` 字段（旧/新两侧 `oldSha/newSha`，缺失 null）。前端对 `fileClass` 为二进制类且两侧均无法出 diff 的条目渲染摘要卡：类型、双端大小、SHA 是否变化（`oldSha === newSha` → 「内容一致」/「内容变化」/「单侧存在」）。
   - **后端改动**（`java_core`）：tree 构建处补齐 sha256 字段；控制在构建期一次计算，不增加二次 IO。
4. 测试：`__tests__/diff_line_select.spec.js`（选择/复制/行号前缀）、`diff_search.spec.js`（纯函数用例：命中偏移/大小写/regex off）、二进制卡渲染用例并入现有 DiffView 相关 spec。

### 2.3 R3 进度分段（改 `components/CompareOverlay.vue` + 后端 jobProgress）

1. **后端**：jobProgress JSON 增加可选 `phase` 枚举（`unpack | compare | decompile | done`）与 `phasePct`（0-100）；在解包器、DiffEngine 主流程、反编译管线三处现有进度上报点附带写入。**兼容性**：字段可选，旧前端忽略不报错。
2. **前端**：CompareOverlay 按 phase 渲染三段进度条（当前段高亮 + 段名：「解包 → 比对 → 反编译」），`progress` 仍作整体百分比兜底展示；phase 缺失时退化为现有单条 bar（老包兼容）。
3. 虚拟滚动/内存部分按评审结论转回归验证：5 万条目首屏 ≤3s 用既有样本包实测；`MemoryReleaseTest` 3 用例回归。

### 2.4 R4 一键整体摘要（改 `components/ToolBar.vue` + `store.js` + `AiConsole.vue`）

1. **入口**：ToolBar 智能分析下拉（既有 categories 目录）顶部置顶项「⚡ 一键摘要」；未比对/分析中禁用态遵循既有按钮规则。
2. **行为**：等价于以 `risk`（整体风险分析）类别发起单类别分析——**复用现有分析任务管线**（含成本闸门、流式输出、Mock 降级），不新增后端接口；摘要完成后 toast 提供「复制 Markdown」（AiConsole 既有输出区加复制按钮，供粘贴进报告）。
3. **约束**：无 Key 时走既有 Mock 降级路径并提示；成本超阈值弹出 CostGateDialog 确认（既有行为，不绕过）。

## 3. 接口定义

| 接口 | 变更 | 说明 |
| --- | --- | --- |
| `GET /api/job/:id/progress`（jobProgress 轮询） | 新增可选字段 `phase: 'unpack'\|'compare'\|'decompile'\|'done'`、`phasePct: number` | R3；前端对缺失字段降级 |

| `state.config` 新键 | `treeFilterBarVisible: boolean`、`diffCopyWithLineNo: boolean` | 前端运行时配置，随既有 config 持久化链路 |
